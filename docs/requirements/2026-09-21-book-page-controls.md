# 打开书籍与翻页入口修复

状态：已实现。

用户反馈：无法执行翻开书观看的操作，远程操作时不能依赖鼠标滚轮。

沿用现有拿书、检阅、翻页与阅读计时系统，不重做交易流程。

- 柜台持书且鼠标可用时，显示「翻开阅读」，一次点击进入检阅并打开第一页；触屏同样可用。
- 夜间自由行走保持鼠标环顾；拿书后按 R 进入检阅，释放鼠标，再点击「翻开」。
- 检阅中桌面和手机共用上一页、下一页和页码；保留滚轮，新增左右方向键。R 保持进入/退出封面检阅的原有语义，便于查损。
- 封面不能继续向前翻，末页不能继续向后翻；动画期间禁用按钮，设置打开时隐藏阅读入口且不翻页。
- 夜间检阅冻结行走与镜头，支持拖动旋转；关闭设置后仍可点按钮，退出检阅恢复环顾。
- 不改变每个未读页停留两秒推进时间的规则，也不改变借还书、质询和推荐判断。

验证：tests/page-controls.mjs 通过真实按钮、方向键、滚轮与拖动检查两条阅读路径、页界、暂停隔离、阅读时间、书架延迟内页与夜间鼠标恢复。
