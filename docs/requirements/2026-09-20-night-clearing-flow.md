# 闭馆清场：巡视、发现滞留读者与劝离

**状态：设计需求 / 待实现**

**对应项目：Nightfall Library / cute_lib**

## 0. 给 Codex 的执行要求

请直接在现有仓库 `WWweiweiHANK/cute_lib` 上实现，不要另建工程，不要重做已有借书、还书、书籍检视、柜台镜头、闭馆阅读转场、夜间自由行走和夜间整理书籍系统。

本需求应接在：

`NIGHT_SHELVING_COMPLETE`

之后。

如果当前分支尚未完成前置的 NIGHT_FREE_ROAM 或 NIGHT_SHELVING，请先阅读并按以下需求文档实现前置：

- `docs/requirements/2026-09-20-closing-reading-transition.md`
- `docs/requirements/2026-09-20-night-shelving-flow.md`

本轮只实现：

> 夜间整理结束 → 玩家开始巡视 → 找到仍然滞留馆内的读者 → 靠近并提醒闭馆 → 对方收拾 / 起身 / 离开 → 全部离开后确认馆内无人。

暂时不要实现：

- 夜间特殊访客
- 推荐书籍
- 工资结算
- 房租
- 第二天
- 超自然事件
- 追逐
- 怪物
- 顾客争吵升级
- 多轮话术树

# 1. 核心体验

这一轮不是“找三个 NPC 打卡”。

玩家应该感觉：

> 书已经整理完了，但还不能马上结束工作。我得走一圈，确认图书馆里没有人还留着。

完整流程：

```text
NIGHT_SHELVING_COMPLETE
↓
短暂安静
↓
玩家继续自由行走
↓
自然经过阅读区、书架和角落
↓
发现仍滞留的读者
↓
靠近 / 对准
↓
轻量提醒“已经闭馆了”
↓
读者回应
↓
起身 / 收东西 / 离开
↓
继续巡视
↓
所有普通读者离场
↓
“馆里已经没人了。”
↓
NIGHT_CLEARING_COMPLETE
```

第一天的情绪仍然是：

**80% Cozy / 15% Lonely / 5% Unease**

不要把这一轮做成恐怖追逐。

# 2. Game Phase

新增：

```js
NIGHT_CLEARING
NIGHT_CLEARING_COMPLETE
```

关系：

```text
NIGHT_SHELVING_COMPLETE
↓
NIGHT_CLEARING
↓
NIGHT_CLEARING_COMPLETE
```

Camera Mode 保持与 Game Phase 分离。

正常巡视：

```text
Game Phase = NIGHT_CLEARING
Camera Mode = FREE_LOOK
```

进入短对话：

```text
Game Phase = NIGHT_CLEARING
Camera Mode = DIALOGUE_FOCUS
```

对话结束：

回到 FREE_LOOK。

不要把清场逻辑塞进借书 / 还书 Transaction。

建议新建：

```text
src/night-clearing.js
```

或：

```js
NightClearingController
```

# 3. 清场开始的提示

夜间整理最后一本书放好后，不要立刻刷出“去赶人”。

保持：

约 1.5～2.5 秒

安静环境。

然后只出现一句很轻的工作提示：

> 还有人没走吗……

约 1.5 秒淡出。

不要显示：

```text
清场任务 0/3
```

不要目标箭头。

玩家应该主动巡视。

---

# 4. 第一版放 3 位普通滞留读者

准备三位风格完全正常的 NPC。

## A：睡着的老年读者

位置：

阅读区桌边。

状态：

- 坐着
- 轻微趴在桌面
- 面前有一本书
- 呼吸缓慢
- 偶尔轻微动一下

玩家靠近约 1.8m 后可交互。

提醒：

> “您好，已经闭馆了。”

老人先慢一点抬头：

> “啊……已经这么晚了。”

停顿约 0.5 秒。

> “不好意思，我这就走。”

随后：

- 合上书
- 起身
- 稍微整理外套
- 朝出口走

不要把老人做成诡异睡姿。

---

## B：戴耳机的年轻读者

位置：

靠窗阅读位或角落桌边。

状态：

- 戴耳机
- 在低头阅读 / 写东西
- 没注意闭馆

玩家第一次靠近时：

对方不立刻反应。

可以需要玩家再靠近一点，或点击一次进行提醒。

玩家：

> “不好意思，图书馆已经闭馆了。”

年轻人抬头：

> “啊？已经关门了吗？”

停顿。

> “抱歉，我没注意时间。”

然后：

- 摘下一边耳机
- 收起书 / 本子
- 起身离开

不要让耳机角色变成“听不见所以要连续点很多次”。

最多一次轻微延迟即可。

---

## C：坐在地上看书的小孩

位置：

低书架旁 / 书架转角。

不是藏在漆黑死角。

玩家从某个角度靠近时，第一眼可能看不到完整身体。

这是第一天唯一允许的轻微“被吓一下”。

方式必须克制：

玩家绕过书架转角
↓
小孩突然站起来 / 从低处进入视线
↓
没有音效爆点
↓
没有黑屏
↓
没有怪脸
↓
只是因为距离近和视线遮挡产生轻微惊一下

小孩看向玩家。

玩家：

> “已经闭馆了，该回家了。”

小孩：

> “哦。”

或者：

> “我再看最后一页。”

停顿约 0.5 秒。

然后：

> “好吧。”

小孩合上书，转身离开。

非常重要：

- 不说神秘台词
- 不警告玩家
- 不提“这里晚上不对劲”
- 不突然消失
- 不再次出现
- 不回头怪笑

就是一个普通小孩。

# 5. NPC 发现方式

不要给 NPC：

- 黄色轮廓
- 发光
- 箭头
- 小地图点
- 头顶感叹号

玩家通过真实空间发现他们。

但不能因为灯光太暗完全看不到。

需要通过：

- 暖光余光
- 椅子 / 桌面构图
- 人物轮廓
- 局部阅读灯

保证合理可见度。

---

# 6. 交互距离

建议：

```js
talkDistance ≈ 1.6 ~ 2.0m
```

超出距离：

不进入可交互状态。

玩家必须真的走到附近。

中心 Raycaster 对准人物后，准星轻微变化。

左键：

触发提醒。

不要使用大型“按 E 对话”。

---

# 7. 自由巡视中的对话镜头

不要切第三人称。

复用现有 DIALOGUE_FOCUS，但参数要适合站立状态。

建议：

- FOV 67° → 63°～64°
- 向前移动 1～2cm
- 约 0.45～0.65 秒进入
- 人物脸落在自然视觉中心附近
- 保留人物上半身与环境
- 不做大特写

与柜台对话相比：

**夜间清场的对话镜头应该更轻。**

因为玩家此时站在空间中。

---

# 8. 对话时的玩家控制

进入短提醒对白后：

- 暂停 WASD 位移
- 鼠标仍允许非常小幅观察
- 不允许玩家走着穿过 NPC
- 不必完全锁死 Camera

对白结束、NPC开始离开时：

立即恢复 FREE_LOOK / WASD。

玩家可以：

- 看着他走
- 转身继续巡视

不要强制跟拍到门口。

---

# 9. NPC 离场路径

三位普通读者都应该有真实离场路径。

建议：

当前位置
↓
最近过道
↓
主要走道
↓
入口
↓
门
↓
离开场景

不要瞬间消失。

不要走穿：

- 桌子
- 书架
- 柜台
- 墙

不需要完整 NavMesh 系统。

第一版可以使用：

- 预定义 Waypoints
- 简单 steering
- 路径节点

每位 NPC 的路径都经过人工检查即可。

# 10. 闭馆后的门怎么让读者出去

前面闭馆阶段已经把入口设为从外部锁定。

这里必须避免逻辑冲突。

规则定义为：

> 闭馆后，门从外侧锁定，但馆内读者仍然可以通过内部推杆 / 内侧把手正常离开。

所以：

玩家不能从门外进入。

玩家本人此阶段也不需要离馆。

普通读者离开时：

- 从内侧推门
- 门短暂打开
- 外面的雨声略增强
- 顾客出去
- 门自动回弹关闭

门状态仍然：

```js
lockedFromOutside = true
canExitFromInside = true
```

不要每离开一个人都“解锁整个图书馆”。

# 11. 离场声音

NPC 离场使用很轻的：

- 椅子摩擦
- 衣物
- 脚步
- 门把
- 门铃 / 门轴
- 短暂更明显的雨声

不要播放任务完成提示音。

# 14. 自由顺序

三位读者必须允许玩家：

任意顺序处理。

例如：

```text
小孩
↓
老人
↓
耳机青年
```

或者：

```text
耳机青年
↓
老人
↓
小孩
```

都成立。

不要做强制线性顺序。

# 15. 不显示剩余人数

普通玩家绝对不要看到：

```text
剩余顾客：2
```

也不要：

```text
1 / 3
```

玩家是否已经走完图书馆，本身就是体验的一部分。

DEV_MODE 可以显示剩余人数。

---

# 16. 玩家可以漏掉人

如果还有一个人没有被找到：

系统不能自动把他赶走。

`NIGHT_CLEARING_COMPLETE`

不得触发。

玩家必须继续巡视。

但也不要不停刷：

> 还有一个人没走！

最多当玩家长时间没有进展时，未来再考虑轻提示。

本轮不做自动提示。

---

# 17. 清场完成判定

当：

```js
visitors.every(v => v.hasExited)
```

成立。

不要立刻抢控制。

保持：

约 1.5 秒

只有环境声音。

然后出现一句：

> 馆里已经没人了。

约 1.5 秒淡出。

随后：

```js
gamePhase = "NIGHT_CLEARING_COMPLETE";
```

---

# 18. 不要立刻结束夜晚

清场完成后：

玩家仍然保持自由移动。

这一状态只是：

> 普通读者已经清空。

下一轮才会接：

**夜间特殊访客 / 推荐书籍。**

不要本轮自动加载下一个玩法。

---

# 19. 小孩“轻微吓一下”的实现边界

第一天的小孩事件是空间惊吓，不是恐怖事件。

允许：

- 书架遮挡
- 玩家绕过拐角突然近距离看见
- 小孩在玩家靠近时突然起身

禁止：

- 音效 Stinger
- Camera Shake
- FOV 突变
- 屏幕闪烁
- 面孔畸变
- 瞬移
- 超高速跑动
- 突然贴脸
- 第二次出现

玩家应该只是：

> “哦，原来这里还有个小孩。”

而不是：

> “游戏在 Jump Scare 我。”

---

# 20. 第一日不增加规则复杂度

三位读者都愿意正常离开。

不要出现：

- 拒绝离开
- 讨价还价
- 暴躁争执
- 需要找证据
- 需要管理员权限
- 需要报警

这些可以以后再做。

第一日的目的只是让玩家理解：

**整理完书以后，还要走一圈清场。**

---

# 21. 清场与夜间整理可以共享空间

不要重新布置另一张地图。

读者的位置应与前一阶段整理路线有关系。

例如：

- 老人：阅读桌
- 青年：窗边
- 小孩：书架区

这样玩家已经整理书时见过这些区域。

但是整理时 NPC 可以存在并继续做自己的事情。

建议：

在 NIGHT_SHELVING 时：

这些读者已经坐在那里。

玩家可以看见他们。

但还不能正式劝离，直到进入 NIGHT_CLEARING。

这样空间更连续。

不要清场开始时突然刷新三个人。

---

# 22. 如果玩家整理时靠近读者

NIGHT_SHELVING 阶段：

不要触发正式清场对白。

人物可以：

- 看一眼玩家
- 继续读书
- 保持 idle

中心准星不要变成清场交互态。

等：

```text
NIGHT_CLEARING
```

才启用“提醒闭馆”。

# 23. 小孩的出现方式也不要凭空 Spawn

小孩应该从夜间阶段开始就已经真实存在于世界。

例如一直坐在：

低书架另一侧。

只是从多数路线不容易立即看到。

不要玩家进入 NIGHT_CLEARING 才突然 spawn 在背后。

# 34. 本轮最终体验

理想流程：

```text
玩家把最后一本书放回书架。

……

“书都收起来了。”

……

“还有人没走吗……”

玩家继续往前走。

阅读桌边：

一位老人趴着睡着。

“您好，已经闭馆了。”

“啊……已经这么晚了。”

老人起身，慢慢离开。

玩家继续巡视。

窗边青年戴着耳机。

提醒后：

“啊？已经关门了吗？”

收东西离开。

玩家走进书架。

拐过转角。

一个小孩突然从低处站起来。

玩家轻微一惊。

没有恐怖音效。

“已经闭馆了，该回家了。”

“我再看最后一页。”

……

“好吧。”

小孩离开。

玩家继续走一圈。
```
