# 手机远程试玩

**状态：已实现（2026-09-20）**

## 目标

让远程控制 Codex 的玩家无需安装应用，直接在手机浏览器横屏打开当前 `cute_lib` 游戏并体验现有借还书、闭馆阅读和夜间整理。

## 操作

- 手机横屏运行；竖屏显示横屏提示。
- 场景内单指拖动控制视线，点击画面中的物件直接拿取或使用。
- 夜间左下虚拟摇杆移动，右下「使用」对准准星执行拿取或放置。
- R 按钮进入或退出原有书籍检视；检视中拖动旋转，左右按钮翻页。
- 粗指针手机模式不请求 Pointer Lock；检视期间移动冻结。触屏笔记本按当前使用的鼠标或触摸输入切换控制方式，桌面键鼠操作保持不变。
- 摇杆与场景拖动分别绑定各自的手指，双指同时移动和转头时互不抢占。

## 发布

提交到 `main` 后，GitHub Actions 把已验证的 `dist/` 发布到 GitHub Pages。Vite 构建和环境音均使用仓库路径下的相对地址，支持 `https://wwweiweihank.github.io/cute_lib/`。

## 边界

这是触屏适配和公网试玩入口，不改关卡内容、书架规则、存档结构或桌面交互。面向现代手机浏览器；低端设备的帧率取决于 GPU 和浏览器 WebGL 支持。
