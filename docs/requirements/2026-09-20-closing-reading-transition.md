# 闭馆阅读转场与夜间起身流程

**状态：设计需求 / 待实现**

目标：补齐白天工作结束到夜间自由行动之间的生活化转场。玩家不能在最后一位顾客离开后直接进入夜晚，而是要在柜台继续看一会儿自己的书，让时间通过翻页自然推进；到达闭馆时间后，玩家主动说“好了，下班了”，随后才执行闭馆、起身和夜间自由行动。

## 1. 完整流程

最后一位顾客离开 → 门关闭 → 馆内安静 2～3 秒 → 提示“离闭馆还有一会儿。” → 玩家仍坐在柜台后 → 拿起自己的阅读书 → R 进入书籍检视 → 翻页并停留阅读 → 每完成一次有效阅读，游戏时间推进 → 到达 22:00 → 玩家合上并放回书 → 字幕“好了，下班了。” → 进入闭馆转场 → OPEN 变 CLOSED → 锁门与部分灯光变化 → 玩家站起 → 进入夜间自由行动。

## 2. 高层阶段

新增并明确区分：

- DAY_COUNTER：白天柜台工作。
- CLOSING_READING：无顾客后的柜台阅读等待。
- CLOSING_TRANSITION：正式闭馆、锁门、灯光调整、起身。
- NIGHT_FREE_ROAM：夜间自由行动。

交易状态与 Game Phase 必须分离，不能把 TRANSACTION_COMPLETE 直接当作夜晚。

## 3. 私人阅读书

柜台上增加一本只属于玩家的 personalReadingBook。它不是馆藏交易物品，不进入借还数据库，不参与损坏判断、顾客拿取或书架分类，只承担闭馆前等待和时间推进。

视觉保持普通、克制、生活化。可暂定书名《夜航》或《雨停之前》，使用深灰蓝封面、米白纸张、小标题，不使用怪谈或恐怖图案。

## 4. 阅读交互

继续复用现有书籍语言：点击拾取 → 右手持有 → R 进入 OBJECT_INSPECT → 滚轮翻页 → R 退出。不要增加“阅读模式”按钮。

阅读构图可以比馆藏检查略低，让书位于画面下半部，同时保留空柜台、远处书架和雨窗，强化“值班空档坐着看书”的感觉。

CLOSING_READING 阶段仍禁止 WASD，自始至终保持坐在柜台后的有限视角，直到正式闭馆。

## 5. 时间推进

测试时间可从 21:35 开始，例如：第一段阅读后 21:43，第二段 21:51，第三段 21:58，第四段 22:00。具体分钟数属于调试参数，但必须体现“翻阅几次后才到闭馆时间”。

翻页本身不能立刻刷时间。进入一个新的阅读页后，需要停留约 1.5～2.5 秒，才算完成一次有效阅读推进；同一页不能反复触发时间推进。

退出阅读后，已读页数与已推进时间保留；重新拿起书可以继续读，不能重置。

右上角现有时钟以轻微淡变更新即可，不显示“TIME +8 MIN”、进度条或大型时间提示。

随着时间推进，可让环境发生非常轻微的变化，例如远处某盏阅读灯逐渐降低亮度、窗外冷色稍微明显，但不能突然变黑。

## 6. 阅读内容

准备约 4～5 个短页，每页约 30～60 字，内容围绕雨夜、城市、旅途、灯光等普通文学意象。第一天不要出现图书馆怪谈、异常文字、自动翻页、时间倒退或任何超自然暗示。

预留 readingEvents 数据接口即可，当前必须为空。

## 7. 到达闭馆时间

currentTime >= 22:00 后设置 closingReady = true。不要立即抢走玩家控制，让玩家读完当前页。

随后可以出现一次很轻的“已经到闭馆时间了。”提示。玩家退出阅读后，书以约 0.4～0.6 秒的动画合上并回到固定桌面位置。

书放稳以后，玩家角色第一次主动出现一句普通字幕：

> 好了，下班了。

语气应平常、稍微疲惫、自然，不要表现成害怕或剧情腔。

该字幕结束后停顿约 0.7 秒，才进入 CLOSING_TRANSITION。

## 8. 正式闭馆

顺序必须是：先读书等时间 → 到点 → “好了，下班了” → 再正式闭馆。不要先 CLOSED 再继续看书。

闭馆阶段执行：OPEN 翻为 CLOSED；门锁发出轻微咔哒声；阅读区和入口部分灯光降低约 15%～25%；柜台台灯与安全照明继续保留。目标是暖光区域更孤立，而不是把场景变黑。

## 9. 起身与夜间自由行动

正式闭馆后再执行站起动画：摄像机轻微后移 5～10cm，高度增加约 12～20cm，加入轻微椅子或衣物摩擦声，总时长约 0.8～1.2 秒，全程第一人称，不黑屏、不切镜。

站起后解除柜台 ±5° / ±3° 限制，进入 NIGHT_FREE_ROAM。夜间自由行动的具体移动、碰撞、Pointer Lock、空间音和书架整理属于下一阶段实现，本需求只要求为它完成自然衔接。

## 10. Cozy Horror 情绪目标

这一段应该是整天最安静、最 Cozy 的阶段：暖色台灯、空柜台、外面下雨、玩家翻自己的书、时间一点点过去。不要加入鬼影、灯闪、怪声、背后有人或任何异常。

核心体验不是“按按钮进入夜晚”，而是“我真的坐在这里工作到了闭馆时间”。

## 11. 开发入口与测试要求

新增开发入口 `?mode=closing`，开发模式可使用 `?dev=1&mode=closing` 直接进入最后顾客刚离开的状态。

DEV_MODE 可显示 Game Phase、Current Time、Current Reading Page、Page Dwell Time、Reading Advances、Closing Ready；正式模式全部隐藏。

建议新增 `tests/closing-reading.mjs`，至少验证：进入 CLOSING_READING；此阶段无法 WASD；私人书可拾取并 R 检视；翻页后必须满足停留阈值才推进时间；同页不能重复刷时间；退出后进度保留；重新进入可继续；到 22:00 后 closingReady 为 true；书正确回桌；出现“好了，下班了”；随后才进入 CLOSING_TRANSITION；CLOSED 发生在该台词之后；最终可顺利交接 NIGHT_FREE_ROAM。

## 12. 本轮边界

本轮不要同时加入夜间整理、散落书籍、驱赶顾客、神秘访客、工资、房租和超自然事件。

下一轮才进入：夜间自由行动中的“散落书籍 → 拾取 → R 检视 → 判断类别 → 找到对应书架 → 放回”，允许放错且不即时反馈。
