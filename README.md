# 夜阑图书馆 / Nightfall Library

独立制作的 Three.js 第一人称柜台 Demo。参考提供的低多边形雨夜图书馆画面；没有读取、复制或修改 `Afterhours` 工程。角色、物件、纹理和雨在本地程序化生成；环境声使用两份已下载到项目的 CC0 音频，试玩无需外网。

## 运行

Windows 双击 **启动图书馆.cmd**，访问 <http://127.0.0.1:5180/>。需要已安装 Node.js 22.12+；现在直接运行随项目保存的 `dist/` 成品，不调用 npm、不联网安装，也不依赖 Codex 的开发服务。保留启动窗口，关闭即停止；再次双击会复用已经启动的同一游戏。

上一版启动文件的 LF/中文编码组合会被 Windows 批处理错误解析。现已改为 ASCII + CRLF，并用 `.gitattributes` 固定换行。请不要直接双击 HTML；浏览器的 ES Module 需要本地服务。若 5180 被其他应用占用，窗口会显示原因，可以设置 `NIGHTFALL_PORT` 改用其他端口。

需要修改源代码时，在本目录运行开发服务：

```sh
npm ci
npm run dev
```

开发服务在 <http://127.0.0.1:5178/>。开发依赖首次安装需要网络；普通试玩不需要安装依赖。修改代码后运行 `npm run build` 更新 `dist/`，再刷新 5180 的试玩页面。

正式构建：`npm run build`，输出在 `dist/`。运行 `npm run preview` 可本地验证正式版本；不要与开发服务同时占用 5178 端口。

## 操作

| 操作 | 输入 |
| --- | --- |
| 小幅转头 | 移动鼠标；水平 ±5°、垂直 ±3° |
| 拾取 / 使用 | 左键点击物件拿到右侧；点击目标位置使用或放回 |
| 证件提问 | 点击证件照片、姓名或有效日期，直接发起对话 |
| 递还证件 | 点击顾客，选择「还给你」或「我还有问题」 |
| 进入 / 退出书籍检视 | R；退出回到右手，证件无需检视 |
| 旋转书籍 | 检视时按住左键拖动，松开有轻微惯性 |
| 翻页 / 合上 | 滚轮向下翻页，向上返回；第一页再向上合上 |
| 借出 / 拒借 | 持书点击右侧扫码机 / 左侧待处理盘 |
| 还书质询 | 检视时短按书上的可疑位置；拖动只旋转，不提问 |
| 正常收书 | R 回到手中，点击左侧木质归还托盘 |
| 声音与操作菜单 | Esc；保留当前持有 / 检视状态 |

没有自由移动。**光标选物与有限头部转动分开**：固定中心射线在 ±5° 的转头限制下无法覆盖参考构图两端，所以采用光标 Raycaster，让玩家在保持构图的同时操作整个桌面。检查书籍时暂停头部输入，退出时保留之前朝向。拒借暂存柜收敛为柜台内的木质暂存盘，使书籍放置更容易看清。

## 完整流程

访客入场 → 放下书和借阅证 → 点击证件在右侧核对、点击字段提问 → 点击顾客并选择递还 → 点击书拿到右侧 → R 检视、拖动旋转、滚轮翻页 → R 回到手中 → 点击扫码机或暂存盘 → 访客离场 → 保存记录。

不再使用核验单勾选，借出或拒借本身表达玩家判断。扫码机不会拒绝不符证件，也不强制提问。提交后不能重复操作或改判。已递还的证件不能再次拾取；若跳过核验，顾客离场前取走桌上证件。拒借后书留在暂存盘。

开始页的「练习访客 01 / 02」可切换案例，每次只处理一名访客。01 的本人和证件一致；02 的本人戴眼镜、发色发型不同，照片仍使用 01 的资料。真人和证件照分别由相同 Profile 字段驱动的 3D / Canvas 绘制器生成。

完成记录存入浏览器本地 `nightfall-transactions`，最多保留最近 100 条；包括 customerId、actualIdentityMatch、playerChecklistIdentity、finalDecision、isCorrect、timestamp。浏览器禁止存储时仍保留当前会话记录并提示，不中断交易。正常界面不显示正确答案或分数。保留旧记录字段 playerChecklistIdentity，新交易该字段为 null，不改写历史记录。

浏览器按端口隔离存储：旧开发入口 5178 的记录仍保留在那里，5180 试玩入口另行记录，不自动迁移或删除。

## 还书测试

开始页选择「还书测试」及访客 01 / 02，或打开 <http://127.0.0.1:5180/?mode=return&case=A> / <http://127.0.0.1:5180/?mode=return&case=B>。01 归还《远方的灯塔》，封面右下有一道划痕；02 归还无损坏的《城市里的雨》。每次只接待一人，重新值班或刷新开始下一次测试。

顾客只放书。点击拿到右手 → R 检视 → 拖动 / 翻页 → 短按损坏位置，会保存书的旋转、四元数及当前页，平移到右侧，并在 0.7 秒内聚焦顾客。书不自动转正或合上，画面保留人物和被指出的损坏；极侧角度会缩短平移距离，避免损坏转到背面，展开书则向右下留出面部空间。顾客解释后选择「要求赔偿」或「不追究」，直接完成处理，书留在归还托盘，顾客离场；无需额外扫码。

也可以 R 返回手中，直接点击归还托盘收书。托盘不识别损坏、不阻止错误接受。划痕、污渍及页面缺角使用原有 Canvas 纹理，不增加损坏网格；真实表面的 UV 区域负责命中，遮挡、背面和其他页不能误点。短按阈值为 250ms / 6px，超出距离或长按后移动只旋转。

新旧损坏及对错不会显示在普通游戏中。数据层支持 `existingDamageBeforeLoan`，对旧损坏索赔仍记为错误；可见损坏纹理不读取责任字段。完成后保存 `transactionType`、`customerId`、`bookId`、`actualDamagePresent`、`actualDamageResponsibility`、`selectedDamageId`、`finalDecision`、`isCorrect`、`timestamp`。仅 `?dev=1&mode=return&case=A` 提供状态、姿态及结果诊断。

## 当前美术与声音

光照改为更暗的背景与局部暖光，保留人物脸和纸面阅读照明。降低高频木纹、书架细碎书脊、衣服流苏与页块分层。静态环境约 6,200 三角面，访客 A 为 587、B 为 765，操作书为 140；场景主体约 6,900 三角面，比初版约 8,400 减少约 18%（不含雨线、阴影/后处理重复绘制）。

两层声音：[室内轻雨 / Rvgerxini](https://freesound.org/people/Rvgerxini/sounds/508962/) 与 [房间设备底噪 / stomachache](https://freesound.org/people/stomachache/sounds/192529/)，均标注 CC0。来源与实际文件 URL 见 `public/audio/SOURCES.md`。默认环境滑杆 28%，对音频归一化并限制峰值，加入低通与 0.7 秒循环交叉淡化；两层音量分别按 47 / 71 秒缓慢变化，没有雷声或突发大音效。文件加载失败时保留很轻的合成底噪，不阻断游戏。

开发模式：<http://127.0.0.1:5178/?dev=1&case=B>。`src/main.js` 的 `DEV_MODE` 由 `?dev=1` 显式打开；角落显示实际身份、状态、玩家判断和结果，控制台暴露只读 `window.library` 诊断。普通入口关闭开发模式。

## 结构

- `src/transaction.js`：交易状态与提交规则，与绘制解耦。
- `src/main.js`：摄像机、鼠标射线、检查与放置动画、流程、UI、记录。
- `src/assets.js`：Profile、角色、证件照、厚书与铰链封面、材质。
- `src/environment.js`：柜台、书架、入口、阅读区、灯光、窗外雨与湿地反光。
- `src/audio.js`：雨声、通风底噪、门铃、纸张与扫码反馈，点击开始后启用。
- `public/audio/`：本地环境声素材及来源记录。
- `tools/launch.mjs`、`启动图书馆.cmd`：无 npm 依赖的成品本地服务与 Windows 入口。
- `src/style.css`、`index.html`：轻量工作提示、证件热点、递还选择、开始与结束界面。
- `tests/`：状态规则与浏览器完整流程验证；截图写入 `artifacts/`。

## 柜台式对话镜头

保持第一人称，不切镜头。普通柜台视角 FOV 67°、水平 ±5° / 垂直 ±3°；对话用 0.7 秒渐变至 FOV 62°，前移 3cm，注意力落在人物面部附近，保留雨窗和上半身。鼠标输入为平时 0.6 倍，额外转头限制在水平 ±2.5° / 垂直 ±2°内。

开场沿「脸 → 手与书 → 脸 → 手与证件」进行；放物时在 0.5 秒内向下跟随 2°，最后停顿并用 0.5 秒回到普通视角。扫码声之后保持 0.25 秒再聚焦，说完「谢谢」停顿后再说「晚上辛苦了」。拒借保持 0.3 秒，随后用 0.8 秒回看顾客，沉默后说「那算了」。离场前恢复普通视角，不跟拍背影。

证件提问与递还使用相同的轻聚焦；右侧证件仍能看见。书籍 R 检视使用独立 OBJECT_INSPECT 状态，暂停普通转头和对话聚焦，保留旋转、翻页。对话镜头测试记录实际每帧 FOV 与相机位置，检查平滑过渡、停顿、鼠标仍能转头、物品跟随及离场交接。

## 克制的常驻界面

常驻仅保留低亮度馆名与 21:47。DAY 01 开场显示 2 秒；处理借阅提示短暂出现后消失。操作提示仅首次显示 5 秒。Esc 打开声音与操作设置，R 专门用于进出书籍检视。

## 版本管理

每轮完成修改后验证、更新变更记录、提交并推送到 origin/main。dist 成品随源代码提交，克隆后安装 Node.js 即可双击启动；修改源代码后先重新构建。
