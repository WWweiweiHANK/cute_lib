# 夜阑图书馆 / Nightfall Library

独立制作的 Three.js 第一人称柜台 Demo。参考提供的低多边形雨夜图书馆画面；没有读取、复制或修改 `Afterhours` 工程。角色、物件、纹理和雨在本地程序化生成；环境声使用两份已下载到项目的 CC0 音频，试玩无需外网。

## 运行

Windows 双击 **启动图书馆.cmd**，访问 <http://127.0.0.1:5180/>。需要已安装 Node.js 22.12+；现在直接运行随项目保存的 `dist/` 成品，不调用 npm、不联网安装，也不依赖 Codex 的开发服务。保留启动窗口，关闭即停止；再次双击会复用已经启动的同一游戏。

上一版启动文件的 LF/中文编码组合会被 Windows 批处理错误解析。现已改为 ASCII + CRLF，并用 `.gitattributes` 固定换行。请不要直接双击 HTML；浏览器的 ES Module 需要本地服务。若 5180 被其他应用占用，窗口会显示原因，可以设置 `NIGHTFALL_PORT` 改用其他端口。

需要修改源代码时，在本目录运行开发服务：

```sh
npm ci
npm run dev
```

开发服务在 <http://127.0.0.1:5178/>。开发依赖首次安装需要网络；普通试玩不需要安装依赖。修改代码后运行 `npm run build` 更新 `dist/`，再刷新 5180 的试玩页面。

正式构建：`npm run build`，输出在 `dist/`。运行 `npm run preview` 可本地验证正式版本；不要与开发服务同时占用 5178 端口。

手机可横屏打开 <https://wwweiweihank.github.io/cute_lib/> 直接试玩，无需安装。左下摇杆用于夜间行走，场景内拖动转头，右下按钮负责使用、R 检视和翻页；竖屏会提示旋转设备。触屏笔记本在使用鼠标后仍采用桌面键鼠操作。

## 操作

| 操作 | 输入 |
| --- | --- |
| 小幅转头 | 移动鼠标；水平 ±5°、垂直 ±3° |
| 拾取 / 使用 | 左键点击物件拿到右侧；点击目标位置使用或放回 |
| 证件提问 | 点击证件照片、姓名或有效日期，直接发起对话 |
| 递还证件 | 点击顾客，选择「还给你」或「我还有问题」 |
| 进入 / 退出书籍检视 | R；退出回到右手，证件无需检视 |
| 旋转书籍 | 检视时按住左键拖动，松开有轻微惯性 |
| 翻页 / 合上 | 滚轮向下翻页，向上返回；第一页再向上合上 |
| 借出 / 拒借 | 持书点击右侧扫码机 / 左侧待处理盘 |
| 还书质询 | 检视时短按书上的可疑位置；拖动只旋转，不提问 |
| 正常收书 | R 回到手中，点击左侧木质归还托盘 |
| 声音与操作菜单 | Esc；保留当前持有 / 检视状态 |

手机横屏中，点击物件直接使用；夜间自由行走时以准星瞄准，再按右下「使用」。检视中拖动旋转书，使用左右按钮翻页，R 退出；双指可同时操作摇杆和视角。

柜台工作时不能自由移动，闭馆起身后可在馆内行走。**光标选物与有限头部转动分开**：固定中心射线在 ±5° 的转头限制下无法覆盖参考构图两端，所以采用光标 Raycaster，让玩家在保持构图的同时操作整个桌面。检查书籍时暂停头部输入，退出时保留之前朝向。拒借暂存柜收敛为柜台内的木质暂存盘，使书籍放置更容易看清。

## 完整流程

访客入场 → 放下书和借阅证 → 点击证件在右侧核对、点击字段提问 → 点击顾客并选择递还 → 点击书拿到右侧 → R 检视、拖动旋转、滚轮翻页 → R 回到手中 → 点击扫码机或暂存盘 → 访客离场 → 保存记录。

不再使用核验单勾选，借出或拒借本身表达玩家判断。扫码机不会拒绝不符证件，也不强制提问。提交后不能重复操作或改判。已递还的证件不能再次拾取；若跳过核验，顾客离场前取走桌上证件。拒借后书留在暂存盘。

开始页的「练习访客 01 / 02」可切换案例，每次只处理一名访客。01 的本人和证件一致；02 的本人戴眼镜、发色发型不同，照片仍使用 01 的资料。真人和证件照分别由相同 Profile 字段驱动的 3D / Canvas 绘制器生成。

完成记录存入浏览器本地 `nightfall-transactions`，最多保留最近 100 条；包括 customerId、actualIdentityMatch、playerChecklistIdentity、finalDecision、isCorrect、timestamp。浏览器禁止存储时仍保留当前会话记录并提示，不中断交易。正常界面不显示正确答案或分数。保留旧记录字段 playerChecklistIdentity，新交易该字段为 null，不改写历史记录。

浏览器按端口隔离存储：旧开发入口 5178 的记录仍保留在那里，5180 试玩入口另行记录，不自动迁移或删除。

## 还书测试

开始页选择「还书测试」及访客 01 / 02，或打开 <http://127.0.0.1:5180/?mode=return&case=A> / <http://127.0.0.1:5180/?mode=return&case=B>。01 归还《远方的灯塔》，封面右下有一道划痕；02 归还无损坏的《城市里的雨》。每次只接待一人，重新值班或刷新开始下一次测试。

顾客只放书。点击拿到右手 → R 检视 → 拖动 / 翻页 → 短按损坏位置，会保存书的旋转、四元数及当前页，平移到右侧，并在 0.7 秒内聚焦顾客。书不自动转正或合上，画面保留人物和被指出的损坏；极侧角度会缩短平移距离，避免损坏转到背面，展开书则向右下留出面部空间。顾客解释后选择「要求赔偿」或「不追究」，仅处理这一处损坏，然后回到右手。仍可 R 检查其他位置，最后主动点击归还托盘才完成整笔交易；不需要扫码。

也可以 R 返回手中，直接点击归还托盘收书。托盘不识别损坏、不阻止错误接受。划痕、污渍及页面缺角使用原有 Canvas 纹理，不增加损坏网格；真实表面的 UV 区域负责命中，遮挡、背面和其他页不能误点。短按阈值为 250ms / 6px，超出距离或长按后移动只旋转。

新旧损坏及对错不会显示在普通游戏中。数据层支持 `existingDamageBeforeLoan`，对旧损坏索赔仍记为错误；可见损坏纹理不读取责任字段。完成后保存 `transactionType`、`customerId`、`bookId`、`bookInstanceId`（记忆模式）、`actualDamagePresent`、`actualDamageResponsibility`、`selectedDamageId`、`damageDecisions`、`finalDecision: "accept"`、`isCorrect`、`reason`、`errors`、`timestamp`。每处损坏独立记录，重复决定更新同一项，不累计多份赔偿。旧记录保持原样。仅 `?dev=1` 提供状态、姿态及结果诊断。

## 跨交易记忆循环

开始页选择「记忆循环测试」，或打开 <http://127.0.0.1:5180/?mode=memory>。这是三笔业务的会话测试。最后一位访客离开后，会自然接入闭馆阅读与夜间整理。

1. 林舟借《远方的灯塔》：封面右下折角已存在，证件与本人一致。
2. 他离开后安静 5 秒，周宁借无损坏的《城市里的雨》，证件也正常。
3. 周宁离开后安静 10 秒，林舟回来归还同一实体副本。折角保留，第三页出现脚本指定的咖啡污渍。

间隔没有黑屏、加载或新提示，玩家仍可小幅转头。林舟复用同一人物模型与 Profile，灯塔书复用同一 Mesh 与 BookInstance。书的定义与实体状态分开：借出保存当前损坏 ID、持有人与 ON_LOAN 状态；归还前追加一次污渍，进入 IN_RETURN_TRANSACTION；放入托盘、顾客离场后回到 IN_LIBRARY，清空持有人，所有损坏保留。

玩家可指出折角、污渍，或完全不质询就收书。折角不追究、污渍要求赔偿后收书为正确路线；错罚旧损坏记录 `charged_existing_damage`，放过或漏查污渍记录 `missed_new_damage`。界面不显示历史、损坏总数、检查进度或对错。若第一笔拒借，后面不会凭空生成林舟的归还，周宁业务结束后进入闭馆阅读。

实体状态只在当前页面会话中持续；刷新 / 重新值班会重置测试，已完成交易仍保留在本地记录中。开发入口 <http://127.0.0.1:5178/?dev=1&mode=memory> 可查看副本、持有人、损坏来源、序列位置与逐处决定。普通入口无此诊断。

## 当前美术与声音

光照改为更暗的背景与局部暖光，保留人物脸和纸面阅读照明。降低高频木纹、书架细碎书脊、衣服流苏与页块分层。整理区有 19 本可操作实体书、24 个槽位；没有物理引擎或新增依赖。固定书架灯只照亮标签、书脊与附近地面，柜台暖光继续保留。

两层声音：[室内轻雨 / Rvgerxini](https://freesound.org/people/Rvgerxini/sounds/508962/) 与 [房间设备底噪 / stomachache](https://freesound.org/people/stomachache/sounds/192529/)，均标注 CC0。来源与实际文件 URL 见 `public/audio/SOURCES.md`。默认环境滑杆 28%，对音频归一化并限制峰值，加入低通与 0.7 秒循环交叉淡化；两层音量分别按 47 / 71 秒缓慢变化，没有雷声或突发大音效。文件加载失败时保留很轻的合成底噪，不阻断游戏。

开发模式：<http://127.0.0.1:5178/?dev=1&case=B>。`src/main.js` 的 `DEV_MODE` 由 `?dev=1` 显式打开；角落显示实际身份、状态、玩家判断和结果，控制台暴露只读 `window.library` 诊断。普通入口关闭开发模式。

## 结构

- `src/transaction.js`：交易状态与提交规则，与绘制解耦。
- `src/memory-loop.js`：书籍定义、会话实体、三笔业务数据与顺序控制。
- `src/closing-reading.js`：私人书内容、有效阅读停留与闭馆时间。
- `src/night-shelving.js`：书籍分类、19 本实体状态、24 槽位与最终整理记录。
- `src/night-world.js`：实体书/槽位装配、固定家具碰撞与行走。
- `src/night-clearing.js`：三位滞留读者、提醒状态、起身表现与离场路径。
- `src/night-recommendation.js`：门外访客、请求与一次推荐结果、演出及归架完成判断。
- `src/main.js`：摄像机、鼠标射线、检查与放置动画、流程、UI、记录。
- `src/assets.js`：Profile、角色、证件照、厚书与铰链封面、材质。
- `src/environment.js`：柜台、书架、入口、阅读区、灯光、窗外雨与湿地反光。
- `src/audio.js`：雨声、通风底噪、门铃、纸张与扫码反馈，点击开始后启用。
- `public/audio/`：本地环境声素材及来源记录。
- `tools/launch.mjs`、`启动图书馆.cmd`：无 npm 依赖的成品本地服务与 Windows 入口。
- `src/style.css`、`index.html`：轻量工作提示、证件热点、递还选择、开始与结束界面。
- `tests/`：状态规则与浏览器完整流程验证；截图写入 `artifacts/`。

## 柜台式对话镜头

保持第一人称，不切镜头。普通柜台视角 FOV 67°、水平 ±5° / 垂直 ±3°；对话用 0.7 秒渐变至 FOV 62°，前移 3cm，注意力落在人物面部附近，保留雨窗和上半身。鼠标输入为平时 0.6 倍，额外转头限制在水平 ±2.5° / 垂直 ±2°内。

开场沿「脸 → 手与书 → 脸 → 手与证件」进行；放物时在 0.5 秒内向下跟随 2°，最后停顿并用 0.5 秒回到普通视角。扫码声之后保持 0.25 秒再聚焦，说完「谢谢」停顿后再说「晚上辛苦了」。拒借保持 0.3 秒，随后用 0.8 秒回看顾客，沉默后说「那算了」。离场前恢复普通视角，不跟拍背影。

证件提问与递还使用相同的轻聚焦；右侧证件仍能看见。书籍 R 检视使用独立 OBJECT_INSPECT 状态，暂停普通转头和对话聚焦，保留旋转、翻页。对话镜头测试记录实际每帧 FOV 与相机位置，检查平滑过渡、停顿、鼠标仍能转头、物品跟随及离场交接。

## 克制的常驻界面

常驻仅保留低亮度馆名与时钟；闭馆阅读时由 21:47 逐步走到 22:00。DAY 01 开场显示 2 秒；处理借阅提示短暂出现后消失。操作提示仅首次显示 5 秒。Esc 打开声音与操作设置，R 专门用于进出书籍检视。

## 闭馆阅读与夜间整理

正常流程在最后一名顾客离开、门关上后安静 2.5 秒，提示「离闭馆还有一会儿」。点击柜台右侧自己的《夜航》，R 检视，滚轮翻页；每个未读页停留 2 秒推进一次时间，四页到 22:00。同页重读不能刷时间，退出、放下、再拿起不丢进度。到点后仍可继续看，主动 R 退出才合书放回桌面，说「好了，下班了」。台词结束再等 0.7 秒，门牌改 CLOSED，入口/阅读区/书架灯降低 20%，柜台台灯与安全光保留；相机用 1 秒升高 18cm、后移 8cm，原地站起。

点击画面开始环顾，WASD 行走；沿柜台左右出口进入馆内。墙、窗、柜台、阅读桌椅、书架与花盆有碰撞，不能穿过。手里一次一本书：对准书左键拿起，R/拖动/滚轮仍是原来的检视操作；检视期间行走和视角暂停，Pointer Lock 保持。Esc 释放鼠标并打开设置，返回后继续操作。

阅读桌、桌下、椅边、雨窗边、过道和柜台外有六本散落书。通过标题、封面、书脊与内页判断文学、历史、自然或科普，走到带世界内标签的书架，对准实际空位左键放入；上/下、左/右槽位分别命中，动画约 0.38 秒。距离从手部高度计算约 1.5m，同时限制视线射程 2.4m，以便站立时捡到地面书；实体家具遮挡拾取。占用位置不叠放、不换书。

原架上 13 本书（包含《夜空图鉴》）和刚放进去的书都能拿回重排。类别放错不会被拦截或提示；六本任务书全部入架且空手时，只短暂说「书都收起来了」。清场开始前再次拿书会撤销整理完成状态。最终记录包含全部可操作书的最终位置与分类判断，正确数/错误数只在 DEV 中可见，未接入工资。书架布局和阅读进度只保留在当前页面会话，刷新重置；既有借还记录不受影响。

## 闭馆清场

六本散落书全部入架且空手后，安静 2 秒，短暂提示「还有人没走吗……」，进入清场。老人、戴耳机的年轻人和书架后的孩子在整理阶段就已留在馆内；清场开始后，空手走到 1.8m 内、准星对准人物，左键（手机「提醒」）说闭馆提醒，顺序自由，没有人数或箭头提示。

对话用 0.55 秒轻聚焦，FOV 67° → 63.5°、前移 1.5cm；暂停行走，仍能略微转头。老人慢慢醒来，青年迟一拍回应，孩子只起身一次。读者收书起身后恢复自由行走，沿家具之间的路径走到出口，避让玩家、依次通过门口。门保持外锁内出，开门时雨声稍近，离场后关门；镜头不跟随。

三人实际离开后安静 1.5 秒，显示「馆里已经没人了。」1.5 秒，再进入 NIGHT_CLEARING_COMPLETE，仍能走动和整理书架，随后衔接门外推荐事件。清场状态仅保留当前页面会话，刷新重置。

直接试玩：<http://127.0.0.1:5180/?mode=clearing>；加 `&dev=1` 可查看只读读者状态和门锁诊断。开发服务启动后运行 `npm run test:clearing`，验证两种顺序、并发离场、距离、镜头、碰撞、完成条件和普通 UI；设置 `NIGHTFALL_URL=http://127.0.0.1:5180` 可验收成品。

## 夜间推荐

清场确认消失后保留约 6.5 秒安静和自由行动，陈遥从窗外侧边走到锁着的玻璃门前，轻敲三下。玩家自己走到 1.9m 内并瞄准他，左键 / 手机「询问」听需求：给妹妹找一本图多、简单的星空书。镜头轻聚焦，仍能略微转头；门保持关闭，访客始终在外面。

《夜空图鉴》从开始就在科普书架的普通槽位中，含月相、北斗七星和行星三页图文；其他馆藏仍可选择。拿书、R 检视、拖动和翻页沿用原操作，近处书架与门把手不再遮住手持书。提交前可自由换书，空手回门口可重问需求，首次对话允许手里已有书。

听完需求后，持书回门口点击「推荐这本」才提交，一人只接受一次。正确或不合适都只通过自然对白反馈，访客点头、后退、转身走出雨夜，书仍在玩家手中。推荐书回到任意空槽、玩家空手且访客实际离场，才进入 NIGHT_RECOMMENDATION_COMPLETE；放错分类允许，后台继续记录布局。此处结束，不增加工资或第二天。
